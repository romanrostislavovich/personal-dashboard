Как устроено

без знакаИщет всё сразу: разделы, записи всех модулей (как сейчас), и предлагает действие из текста. >Только команды: синхронизация, проверка подключений, выгрузка, тема, «Настроить главную», «Бережный день». /Перейти в раздел: «/фин» → Финансы, «/фин оп» → Финансы · Операции (вкладки тоже ищутся). ?Вопрос к AI, ответ — прямо в палитре, с кнопкой «Открыть в чате».
  • Размер: 640 px шириной, по центру, в 20 % от верха; на телефоне — на весь экран, строка ввода сверху, клавиатура открыта сразу.
  • Строки 44 px (на телефоне 56), выбранная — secondary-container, совпадение — primary жирным.
  • Загрузка поиска по серверу — тонкая полоса под строкой ввода; локальные результаты (разделы, команды) видны сразу, не ждут сервер.
  • Ошибка сервера — одна строка «Поиск по записям не ответил · Повторить», разделы и команды при этом работают.
  • Ничего не найдено — не пустота, а «Создать задачу «…»» и «Спросить AI».
  • Однобуквенные клавиши (T, E, D) работают, только когда строка пустая.
