# Redesign, round 3 — the whole portal in the A1 style

Start at [index.html](index.html). Every screen has a **1440 / 390** switch (the phone view is the same
file in a 390 × 844 frame), a theme switch and designer notes (purple; not part of the app). Texts in
the mockups are Russian; the mockups are static HTML with a few lines of inline JS and no assets but
Google Fonts. They were generated by a throwaway script; edit the HTML directly from now on.

## 1. The concept in short

- **One style for every page — A1 «Три этажа».** Graphite base; colour only for status (green, amber,
  red) and for the answer (teal). Numbers in JetBrains Mono. Cards are quiet and alike.
- **Every page starts with an answer**, then the numbers that prove it, then the details folded.
- **The A1 status line becomes the top toolbar of every page** (compact on section pages, full on
  home); the bell moves there; «+» quick add sits next to it. On the phone, one red line appears under
  the top bar only when something is wrong.
- **Menu as now** (the owner's answer): Home, AI, Finance, Life and five folded groups; Achievements
  (level ring), System (status dot) and Settings at the bottom. Phone: bottom bar + «Ещё» sheet.
- **Home** = briefing «Ответы на сегодня» (always on top) + «Главное сегодня» + «Скоро» (from B1) +
  the head of «Сигналы» (from C2) + the owner's own widgets.
- **Telemetry gets a smart search**: a phrase («когда я ложился позже часа») → «Понял так» chips
  (signal, condition, period, source — each editable) → a one-line answer, matching **days** on an
  evening scale, **moments** of those nights (including the semantic `/api/ai/recall` index) and the
  **signals** used; then «what these days have in common» from Links and «watch this» → automation.
- **Four page templates** carry every remaining section: section dashboard, list + detail, timeline,
  settings panel and form. At most five tabs; the rest under «Ещё»; section settings live behind ⚙.
- **Honest states everywhere**: skeletons instead of zeros, hatching for unknown days, «рано» when
  there is too little data, errors shown where the data is missing.
