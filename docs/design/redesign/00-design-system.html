Прибор из будущего, который знает ответ

Тот же простой порядок, что и в первом варианте: одно главное на экране, остальное по клику. Сверху ложится новый слой. Основа — графит без цвета. Цвет появляется только в двух случаях: состояние (норма, внимание, беда) и ответ — прогноз, подсказка, «что будет, если». Прошлое на графиках нейтральное, будущее светится.

1. Основа — графит

Карточка--pd-card = container-low #111418
Поле, подложкаcontainer-high #1d2228

Как это делается в приложении: generatePalette(seed, neutral = true) уже умеет нейтральную схему («серая тема»). Графит — это она, с поверхностями чуть холоднее, как у чёрной OLED-темы (BLACK_SURFACES).

2. Цвет ответа новое

Ответ--pd-oracle #5eead4 / светлая #0f766e
Подложка ответа--pd-oracle-container 9 %
Разброс прогноза--pd-forecast-band 14 %
Свечение--pd-oracle-glow

Спокойный бирюзовый: не путается ни с зелёным «норма», ни с жёлтым «внимание». На экране его одно-два пятна: карточка ответов, кольцо уровня, пунктир прогноза. Если светится всё, не светится ничего.

3. Состояние (не меняется)

Моноширинные цифры (--pd-font-mono: JetBrains Mono → Cascadia Mono → Consolas) не прыгают при обновлении и дают «приборную» точность. Абзацы моноширинным не пишем — тяжело читать.

Вопрос (mono, тихо) → ответ (крупно, цвет только у сути) → почему → уверенность.

9. Чего не делаем

  • Неон по всему экрану, сетки «киберпанк», сканлайны.
  • Глитч, мерцание, бегущие цифры — мешают читать каждый день.
  • Прогноз без уверенности и без «почему».
  • Стекло (backdrop-filter) на карточках — только у того, что поверх.
  • Моноширинный для текста абзацев.
  • Цвет ответа на кнопках действий — кнопка «Операция» остаётся светлой нейтральной.
