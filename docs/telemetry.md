# What the dashboard collects

One list of every signal the dashboard has about its owner's days — the ground Links v2
([proposals/links-v2.md](proposals/links-v2.md)) builds on. **Keep it up to date:** a new
collector, a new daily number or a change of what is kept is written here in the same change.

Columns: **what** is collected; **how often** (the granularity it is kept at); **where** (the
table); **to Links** — the keys of the daily numbers the section gives Links (`registerDailyMetrics`),
or "—" when the data is not a daily number yet; **notes** — consent, encryption, limits.

Status 2026-10-25. Rows **1–10** of the phone were added on 2026-10-25 (Activity → Phone, card "The phone, an average day").
