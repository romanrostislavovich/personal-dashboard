# Что сделать самому

Шаги, которые Claude сделать не может: нужен твой терминал, твои аккаунты, сервер или
решения. Файл в репозитории, чтобы продолжить на другом компьютере; если репозиторий
публичный, его видят все — личного здесь нет и быть не должно.

## 0. Продолжить на другом компьютере

- `git pull` → `npm install` (Node 24) → `cp .env.example .env` (тот же `ENCRYPTION_KEY`, что
  и на сервере, если подключаешься к его базе или синхронизации) → `npm run db:up` →
  `npm run dev`.
- Где мы: раздел «Здоровье», этапы 0–5 плана `docs/health.md` сделаны и смержены в `main`.
  Остался этап 6 (позже): напоминания о приёме лекарств, профиль (группа крови, аллергии,
  прививки, операции), импорт из IKP и Helsi.
- Следующие кандидаты из `docs/roadmap.md` → Now: шифрованный внешний бэкап, раздел
  Reliability (повторы задач, таймауты, индексы, `/health`), три идеи для Психологии
  (опросник по расписанию, мягкое предупреждение, события на графике настроения).
- Новому сеансу Claude достаточно сказать: «прочитай `TODO-OWNER.md` и `docs/health.md`,
  продолжаем с …» — контекст этого разговора туда не переедет.

## 1. Срочно: репозиторий и CI

- [ ] **Обновить `package-lock.json`.** Он расходится с `package.json` (не хватает
      `readdirp@4.1.2`, `chokidar@4.0.3`), а CI, Docker и release ставят зависимости через
      `npm ci`. Скорее всего, они уже падают и на `main`. Выполни на Node 24:
      `npm install`, затем закоммить `package-lock.json` отдельным коммитом.
- [ ] **Запушить `main`** (`git push`). Сейчас там непушенные коммиты: аудит roadmap и этап 1
      «Здоровья».
- [ ] **Проверить CI после пуша.** Тесты с реальной базой (`*.db.spec.ts`) локально не
      запускались. Особенно важны миграции `0066_ai_module_connections` и `0067_health`, а также
      синхронизация и корзина на новых таблицах.

## 2. Ключ шифрования: важно

- [ ] **Надёжно сохранить `ENCRYPTION_KEY`** в менеджере паролей, вне сервера. Тексты и
      документы «Здоровья» теперь зашифрованы этим ключом. Потерянный ключ = потерянная
      медицинская история, бэкапы без него бесполезны.
- [ ] **Локальная копия (sync).** Если у тебя есть экземпляр, который синхронизируется с
      сервером, у него должен быть **тот же** `ENCRYPTION_KEY`, что и у сервера.
- [ ] **Шифрованный внешний бэкап** (пункт «Encrypted off-site backup» в roadmap) пока не
      сделан. Пока его нет, медданные живут только на сервере и в его локальных дампах.

## 3. Проверить «Здоровье» вживую

`npm run db:up`, затем `npm run dev`, открыть http://localhost:4200/health.

- [ ] Добавить клинику и врача (Врачи и клиники).
- [ ] Добавить визит к врачу: жалобы, рекомендации, следующий визит.
- [ ] Из визита добавить диагноз, лекарства и скан или фото документа. Открыть документ.
- [ ] Settings → Integrations → «Справочник МКБ»: поставить галочку и скачать МКБ-10 у ВОЗ.
      Потом в форме диагноза найти F41. Если скачивание падает, пришли ошибку из
      Settings → System: разбор формата ВОЗ проверен только на тестовом фрагменте.
- [ ] Settings → AI → «Что видит ИИ»: решить, через какое подключение работает «Здоровье»
      (общее, локальная Ollama или выключено).
- [ ] Вкладка «Анализы»: внести бланк (строки как в бланке: «Глюкоза 5,6 ммоль/л 3,9–5,5»),
      потом второй бланк из другой лаборатории или страны, например в мг/дл. Проверить, что
      показатель стал одной линией на графике, а норма и «вне нормы» видны правильно.
      Посмотреть график в тёмной теме и на телефоне.
- [ ] Если какой-то показатель не распознался по названию, напиши мне название, как в бланке:
      допишу синоним в словарь.
- [ ] Экспорт данных (ZIP): убедиться, что тексты «Здоровья» в архиве читаемые, а не
      шифротекст.

## 3а. Проверить чтение документов AI (этап 3)

- [ ] Для чтения **фото** нужно подключение, которое видит картинки: OpenAI (gpt-4o-mini и
      новее) или Ollama с vision-моделью (например, `qwen2.5vl`). Его надо выбрать в
      Settings → AI («Картинки» или своё подключение для «Здоровья»). DeepSeek картинки не
      читает.
- [ ] Загрузить документ без визита (История → «Добавить документ»), нажать ✨ «Прочитать с
      ИИ». Сверить черновик с оригиналом и сохранить. Проверить, что появились визит, диагнозы
      и лекарства, а документ прикрепился к визиту.
- [ ] Так же проверить бланк анализов (вид «Анализы») и заключение УЗИ или МРТ.
- [ ] Telegram: прислать боту фото документа и выбрать «🩺 Медицинский документ». Открыть
      ссылку из ответа, проверить черновик и сохранить. `PUBLIC_URL` на сервере должен быть
      правильным, иначе ссылка не откроется.
- [ ] Отсканированный PDF без текстового слоя пока не читается: такие документы присылай фото
      страниц.
- [ ] Если на каком-то документе AI ошибается системно (путает поля, переводит текст), пришли
      пример без личных данных: поправлю инструкцию.

## 3б. Проверить выписку для врача (этап 4)

- [ ] Вкладка «Для врача»: польский язык, без перевода, «Открыть для печати» → напечатать в
      PDF. Проверить, как выглядит на бумаге и на телефоне.
- [ ] То же с переводом ИИ: сверить, что коды, числа и названия препаратов не изменились.
- [ ] Исключить «Психиатр» и убедиться, что в выписке нет ни визитов, ни диагнозов, ни
      лекарств оттуда.
- [ ] Создать ссылку на 1 день, открыть её в другом браузере (без входа), потом отозвать и
      убедиться, что она даёт 404.
- [ ] Ссылка ведёт на `PUBLIC_URL/api/medical/shared/...`: проверь, что прокси (Caddy) пропускает
      её снаружи, и что `PUBLIC_URL` — внешний адрес.
- [ ] Отдавая ссылку, помни: у кого ссылка, тот видит выписку до срока. Отзывай, когда врач
      посмотрел.

## 3в. Проверить связи (этап 5)

- [ ] Психология → Паттерны: при назначенных психиатром лекарствах или диагнозах раздела F
      появляется карточка «Во время лечения» со средним настроением за каждый период.
- [ ] История: у каждой строки рекомендаций есть кнопка «В задачи». Задача появляется в TODO.
- [ ] Settings → AI → утренний дайджест: галочка «Ближайшие визиты к врачу». Включить, если
      нужно; данные визита уходят общему AI дайджеста.
- [ ] Ctrl+K: поиск по коду диагноза (F41), названию лекарства, документу.
- [ ] Демо (`DEMO_MODE=true`): в разделе «Здоровье» есть выдуманная история (Киев и Варшава).

## 4. Справочники МКБ на русском и украинском

Распространять их вместе с дашбордом нельзя, поэтому файл скачиваешь ты, а дашборд его
загружает (Settings → Integrations → «Справочник МКБ» → «Загрузить файл», CSV или XLSX со
столбцами «код» и «название»).

- [ ] **Русский (МКБ-10).** Справочник НСИ Минздрава РФ, OID `1.2.643.5.1.13.13.11.1005`:
      https://nsi.rosminzdrav.ru/dictionaries/1.2.643.5.1.13.13.11.1005. Скачать версию в
      CSV или XLSX (на сайте может понадобиться регистрация). Из Польши сайт может не
      открыться, тогда через VPN.
- [ ] **Украинский.** Украина перешла на НК 025:2021 (на основе австралийской МКБ-10-AM), её
      лицензия выдаётся только государствам. Варианты:
  - таблица НК 025:2021 с сайта МОЗ или из справочников eHealth, если найдёшь её в
    открытом доступе (выбрать систему «МКБ-10-AM»);
  - старая украинская МКХ-10 (перевод 1999 года), если есть файл.

  Это только для личного использования, не публиковать. Если файла нет, украинские названия
  будут браться из самих документов.
- [ ] Польские названия так же можно загрузить из файла, если найдёшь (CeZ, PLICD10). Лицензию
      я не проверил.
